1. Bu proje nedir?

StayFinder, otel arama ve detay gösteren bir MVC web uygulamasıdır. Kendi veritabanı yoktur. Otel verisi RapidAPI üzerindeki Booking.com 15 (booking-com15.p.rapidapi.com) servisinden canlı çekilir. Kullanıcı tarayıcıda form doldurur; sunucu o formu RapidAPI sorgularına çevirir; dönen JSON’u ViewModel’e map’ler; Razor sayfası HTML basar.

Ek olarak eski bir deneme sayfası vardır: ImdbController. StayFinder akışının parçası değildir.

Tek cümle: Bu bir API ürünü değil; API tüketen bir web sitesidir. Dışarıya REST endpoint açmaz, dışarıdan JSON okur.

5. Uygulama ayağa kalkışı (Program.cs)

İstek gelmeden önce host şu sırayla kurulur:

1. WebApplication.CreateBuilder(args)
      ├─ appsettings.json
      ├─ appsettings.{Environment}.json   (Development)
      ├─ ortam değişkenleri
      └─ sonra eklenen: appsettings.Local.json  (optional: true)

2. AddControllersWithViews()
      Controller + Razor aktif

3. Pipeline
      Development değilse  →  /Home/Error + HSTS
      UseHttpsRedirection
      UseStaticFiles          (/css, /lib, görseller)
      UseRouting
      UseAuthorization        (policy yok; varsayılan middleware)
      MapControllerRoute      {controller=Home}/{action=Index}/{id?}

4. app.Run()

Varsayılan rota: boş URL HomeController.Index olur. /Hotel → HotelController.Index. /Hotel/Details/123 yerine query string ile hotelId gider (Detay action’ı id route’una bağlı değildir).

6. Yapılandırma ve sırlar

AnahtarKaynakKullanım
RapidApi:BookingHostappsettings.jsonVarsayılan host: booking-com15.p.rapidapi.com

Program.cs Local dosyayı optional: true okur. Dosya yoksa uygulama açılır ama otel araması “RapidAPI anahtarı bulunamadı” der. Örnek şablon: appsettings.Local.example.json.

Key ≠ JWT token. RapidAPI Application Key’dir. “Bitmesi” çoğu zaman sürenin dolması değil, BASIC planda aylık istek kotasının (HTTP 429) dolmasıdır. Aynı key ile TripAdvisor API’si otomatik çalışmaz; o ürün için ayrı abonelik gerekir. 
{
  "RapidApi": {
    "Key": "BURAYA_RAPIDAPI_KEY"
  }
}

8. Katman 1 — Tarayıcı / Razor

Kullanıcının gördüğü her şey Razor + CSS’tir. StayFinder layout şunları yükler:

  • Google Fonts: Manrope
  • Bootstrap 5.3.3 CSS/JS (CDN)
  • Bootstrap Icons
  • ~/css/stayfinder.css (asp-append-version)

Layout ViewData["Nav"], ViewData["Currency"], ViewData["BodyClass"] okur. Navbar’da aktif menü ve EUR/USD rozeti buradan gelir. Footer sabittir.

Üç ekran

  1. Ana sayfa: kahraman alanı, arama paneli (şehir, tarih, para, yetişkin/çocuk/oda sayaçları), popüler şehir kartları (Milano, Roma, Paris, Barcelona — Unsplash görselleri, sabit liste).
  2. Liste: özet arama çubuğu, boş durum / hata / otel kartları, sol filtre (fiyat, yıldız, puan), sıralama. Filtreler sunucuya gitmez; tarayıcıda kart gizler.
  3. Detay: galeri, adres, puan, fiyat, olanaklar, oda blokları, önemli notlar. Rezervasyon aslında Booking URL’sine (varsa) yönlenir; kendi ödeme sistemi yoktur.

BookingDtos.cs alan adları API’deki gibi durur (dest_id, hotel_id, grossPrice). Newtonsoft varsayılanı birebir isim eşler. Özel durum: politika class alanı C# keyword olduğu için [JsonProperty("class")] public string? kind ile okunur. 

BookingDestinationResponse
  status, message
  data[] → dest_id, search_type, name, label

BookingHotelSearchResponse
  data.hotels[] → hotel_id
                 property.name, reviewScore, photoUrls[],
                 priceBreakdown.grossPrice.value/currency

BookingHotelDetailResponse
  data → hotel_name, address, rooms{}, block[],
         facilities_block, composite_price_breakdown

12. Katman 5 — HTTP istemcisi

Her RapidAPI çağrısı aynı kalıptadır:

GET https://{BookingHost}{path}?{query}

Headers:
  x-rapidapi-key:  {RapidApi:Key}
  x-rapidapi-host: {BookingHost}

Başarı değilse exception fırlatılır; action bunu yakalayıp kullanıcıya Türkçe genel mesaj basar (ham RapidAPI gövdesi ekrana çıkmaz).

15. Otel arama akışı (3 adımlı API)

En kritik akış budur. Örnek: Milano, 15–18 Kasım 2026, 2 yetişkin, 1 oda, EUR.

GET /Hotel?CityName=Milano&CheckIn=2026-11-15&CheckOut=2026-11-18&Adults=2&Rooms=1&Currency=EUR

HotelController.Index
  1) model binding  (query → HotelSearchPageViewModel)
  2) PrepareForm
        CheckIn boşsa  Today+14
        CheckOut boşsa CheckIn+2
        Adults 1..10, Children 0..6, Rooms 1..5
        Currency whitelist
  3) CityName boş mu?
        EVET → View (API yok, boş arama kartı)
        HAYIR ↓
  4) Key yok mu? → ErrorMessage, View
  5) CheckOut <= CheckIn? → hata
  6) CheckIn < Today? → hata
  7) FindDestinationAsync("Milano")
  8) SearchHotelsAsync(dest, model)
  9) Hotels boşsa uyarı
 10) View(Index.cshtml)

15.1 Adım A — Destinasyon

GET https://booking-com15.p.rapidapi.com/api/v1/hotels/searchDestination?query=Milano

Cevaptaki data listesinde önce search_type == "city" olan kayıt seçilir; yoksa ilk kayıt. dest_id ve search_type sonraki çağrıya gider. label sayfada “bölge” metni olur. 

{
  "status": true,
  "data": [
    { "dest_id": "-121726", "search_type": "city", "name": "Milan", "label": "Milan, Italy" }
  ]
}

Sayısal dest_id örnektir; gerçek değer API’den gelir.

15.2 Adım B — Otel listesi

GET .../api/v1/hotels/searchHotels
    ?dest_id=-121726
    &search_type=CITY
    &arrival_date=2026-11-15
    &departure_date=2026-11-18
    &adults=2
    &room_qty=1
    &page_number=1
    &units=metric
    &temperature_unit=c
    &languagecode=en-us
    &currency_code=EUR

Çocuk varsa children_age tekrarlanır: 2 çocuk, yaş 7 → 7,7.

Her otel HotelCardViewModel olur. hotel_id <= 0 veya property == null atlanır. Foto ilk photoUrls[0], fiyat grossPrice.value. 

JSON property                  →  HotelCardViewModel
hotel_id                       →  HotelId
property.name                  →  Name
property.wishlistName          →  City
property.photoUrls[0]          →  PhotoUrl
property.priceBreakdown.grossPrice.value     → Price
property.priceBreakdown.grossPrice.currency  → Currency
property.reviewScore           →  ReviewScore
property.reviewScoreWord       →  ReviewScoreWord
property.reviewCount           →  ReviewCount
property.propertyClass         →  Stars (0 ise null)

15.3 View çıktısı

  • Kart yok + hata yok → “Aramaya başlamak için bir şehir yaz”
  • Kart var → N konaklama, filtreler, sıralama, sayfalama görseli (tek sayfa, gerçek paging yok)
  • Kartın “Detayları Gör” linki tüm arama parametrelerini Details’e taşır ki fiyat/tarih tutarlı kalsın

16. Otel detay akışı

GET /Hotel/Details
    ?hotelId=123456
    &cityName=Milano
    &checkIn=2026-11-15
    &checkOut=2026-11-18
    &adults=2&children=0&rooms=1&childAge=2
    &currency=EUR
    &reviewScore=8.6&reviewWord=Very%20good

Details action
  1) HotelDetailViewModel doldur (form + query)
  2) hotelId <= 0 → hata
  3) key yok → hata
  4) GetHotelDetailAsync
        GET /api/v1/hotels/getHotelDetails?hotel_id=123456&arrival_date=...
  5) data null / status false → "Otel detayı bulunamadı"
  6) Map:
        hotel_name, address+zip+city+country
        photos: rooms[].photos url_max750 (en fazla 12)
        facilities_block + property_highlight_strip
        block[] → en fazla 4 oda kartı
        descriptions: hotel_text + oda açıklamaları (4)
        notes: important_information (3)
        price: composite_price_breakdown.gross_amount
  7) View(Details.cshtml)

Galeri ilk 5 foto. Olanak ikonları view içindeki FacilityIcon ile isimden tahmin edilir (wifi, havuz, spa…). Sunucu tarafında rezervasyon kaydı yoktur.

21. Neye dokunulmaz / sınırlar

  • Veritabanı, kullanıcı hesabı, gerçek rezervasyon yok.
  • Sayfalama API’de page_number=1 sabit; UI’daki sayfa 1 dekoratif.
  • Liste filtreleri sadece o anki HTML kartlarını etkiler.
  • HttpClient her çağrıda new; yüksek trafikte önerilen desen IHttpClientFactory değildir (ama bu ödev ölçeğinde çalışır).
  • TripAdvisor veya başka RapidAPI ürünü mevcut DTO/controller ile drop-in değildir.
  • Ana sayfa destinasyonları API’den gelmez; Razor’da sabit dizi.
  • StayFinder “Hakkımızda / İletişim” linkleri href="#".
Özet zincir: Form (GET) → HotelController → (opsiyonel) searchDestination → searchHotels veya getHotelDetails → DTO → ViewModel → Razor → CSS. Araya başka katman, kuyruk veya veritabanı girmez.
